Neural hacking Normal vs Intervention

Active interventions

Choose an intervention in the Neural inspector, then run a comparison. Normal and Intervention are forked from one identical brain state and given the same random seed, so the only difference between them is the intervention.

  • Suppress is an idealised inhibition. This engine has no inhibitory reversal potential, so a suppression barrage drives the membrane further below rest than a real GABAergic input could. Read it as “strong inhibitory drive”, not as a measured physiological current.
  • Disable does not delete anything from the connectome. The FlyWire wiring is immutable here — every synapse this cell has is still present. Disable holds the cell in the refractory state the engine already implements, so it cannot spike: a simulated silencing, not an edit to the graph.
  • Reaction time is only defined for a channel that was silent before onset. If a channel was already firing in the baseline window, or never fires inside the trial window, no number is shown — the reason is shown instead. No value is ever estimated or written as “more than” the window.
  • One trial per comparison. Normal and Intervention share one seed, so the background noise is identical on both sides and the difference is the intervention rather than luck — but this is still a single run. No statistical significance, p-value or confidence interval is claimed.
