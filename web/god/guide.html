1これは何か

これは、本物のハエ（キイロショウジョウバエ）の脳の配線図をもとに作られた、脳の動きを再現するシミュレーターです。実際に顕微鏡で調べられた、約13万個の神経細胞と、その270万本のつながりのデータをそのまま使っています。

ただし、あなたが直接ハエを歩かせたりジャンプさせたりする操作はできません。あなたが動かせるのは、「ハエの周りの世界」（気温・食べ物のにおい・何かが近づいてくる感覚、など）と、「ハエの脳そのもの」（特定の神経細胞を刺激したり黙らせたりする）の2つだけです。ハエがどう動くかは、その結果として脳が計算した通りに、自動的に決まります。

「You don't control the creature. You control its world and its brain.」
（あなたが操作するのは生き物そのものではなく、その世界と、その脳です。）

言い換えると、これは脳の"シミュレーションゲーム"です。世界に何かを起こす → 脳の中で信号が伝わっていく様子が見える → その結果、ハエがどんな行動を選ぶかが分かる、という一連の流れをそのまま観察できます。

2画面の見方（ざっくり）

起動すると、下のような1枚の画面が表示されます。大きく4つのエリアに分かれています。

  • ① 左（WORLD CONTROL / SCENARIO） — 気温や食べ物など、ハエの「まわりの世界」を操作するスライダーやボタンが並んでいます。
  • ② 中央 — ハエとその世界を3Dで見られる場所です。右上のドロップダウンでカメラの動き方を変えられます。
  • ③ 右（NEURAL ACTIVITY / BEHAVIOR） — 脳の中で今どれくらいの神経細胞が信号を出しているか、そしてハエが今どんな行動をとろうとしているかが表示されます。
  • ④ 下 — 信号が脳の中をどう流れているかの5段階の図、気になる神経細胞を1つずつ検索して調べる場所（NEURAL INSPECTOR）、そして特定の神経細胞に介入して比較実験ができる場所（NEURAL HACKING）が縦に並んでいます。

画面の一番上には「World / Neural / Experiment / Evolution」という4つのタブが並んでいますが、これは見出しのようなもので、押しても画面は切り替わりません。今説明した①〜④の内容が、すべてこの1枚のページの中にすでに収まっています（詳しくは最後の「正直にお伝えする注意点」をご覧ください）。

3各パネルで「何を押すと」「何が起きるか」

WORLD CONTROL 左上のパネル

スライダーやボタンを動かすと、ハエの「感覚」に実際に刺激が送られます。反応は本物のシミュレーション結果で、見た目だけの演出ではありません。

Light（明るさ）NOT CONNECTED

動かしてもハエの脳には何も伝わりません。理由は、このハエの脳のデータの中に「明るさ全体を感じる」ための神経回路が見つかっていないためです（色を感じる非常に狭い回路は別に存在しますが、それとは違います）。存在しない反応をでっち上げるのではなく、正直に「つながっていません」と表示しています。

Temperature（気温）

触角にある温度を感じる神経細胞を刺激します。上げるほど、その神経回路の反応が強くなります。

Humidity（湿度）

湿度を感じる神経細胞を刺激します。

Wind（風）NOT CONNECTED

Lightと同じ理由で、今のところハエの脳には影響しません。風を感じるための神経回路が、このデータの中には見つかっていないためです。

Food（食べ物・ON/OFF）

ONにすると、口先が甘いものに直接触れたときの神経細胞が刺激されます。ハエの「食べようとする行動」に直結する、実験でもよく使われる刺激です。ページ下の BEHAVIOR パネルで「Extending proboscis（口を伸ばす）」に変わるのが見えるはずです。

Food scent（食べ物のにおい）

においを感じる神経細胞を刺激します。Foodが「直接口に触れる」刺激なのに対して、こちらは「遠くからにおいで気づく」刺激です。

Pheromone（フェロモン・ON/OFF）

仲間の匂い（フェロモン）を感じる神経回路を刺激します。求愛行動に関わることがよく知られている経路です。

Visual stimulus / Looming（視覚刺激・ON/OFF）

「何かがどんどん近づいてくる」ように見える視覚刺激を再現します。ハエが危険から逃げる（Escape）反応に強く関わる回路が刺激されます。

Predator（捕食者・ON/OFF）見た目だけ

これをONにしても脳には何も伝わりません。「敵」だけを専門に感じる神経回路はこのデータには存在しないためです。ONにすると3D画面に見た目のオブジェクトが表示されるだけで、上のVisual stimulusとは別物です。

Touch stimulus（接触・ON/OFF）

目のまわりの毛（体の表面のセンサー）に何かが触れたときの神経細胞を刺激します。グルーミング（毛づくろい）行動に関係します。

なぜ Light と Wind、Predator だけ効かないのか このシミュレーターは、実際に観察された神経細胞のデータだけを使っています。「明るさ」「風」「敵そのもの」を専門に感じる神経回路が、今のところこのデータの中には見つかっていません。存在しない反応を偽物の数字で作るくらいなら、正直に「つながっていません」と表示する、という方針で作られています。

SCENARIO 左下のパネル

上の WORLD CONTROL のスライダーを1つずつ動かす代わりに、よくある状況をまとめて再現できるプリセットです。中身は「Default Arena（何もない状態）」「Foraging（採餌中）」「Threat（何かが迫ってくる）」「Courtship（求愛）」「Grooming（毛づくろい）」の5つ。選ぶと、その状況に合ったスライダー・ボタンが自動的にセットされます。特別な処理をしているわけではなく、上のスライダーを手で動かすのとまったく同じ経路で反映されます。

「Reset World」ボタンを押すと、脳の状態（それまでに溜まっていた信号など）と、後述する脳への介入がすべてリセットされ、まっさらな状態からやり直せます。

NEURAL ACTIVITY 右上のパネル

光っている粒の1つ1つが、実際の神経細胞（本物のデータに基づく、約13万個のうちの1つ）です。色は神経細胞の種類（信号を伝えるときに使う化学物質の違い）を表し、明るさは、その細胞が「最近信号を出したかどうか」を表します。信号を出した瞬間は明るく光り、時間が経つとだんだん暗くなっていきます。

数字の「active neurons（活動中の神経細胞）」と「Hz mean rate（平均の発火レート）」は、どちらも今まさにこのページの中で計算されている実測値です。Hz は「1秒間に何回信号を出しているか」を表す単位で、あらかじめ用意された台本の数字ではありません。右上のドロップダウンで、脳の部位（視覚を処理する部分、におい・味を扱う部分など）ごとに絞り込んで見ることもできます。

BEHAVIOR 右下のパネル

脳の中の信号を、「歩く」「止まる」「口を伸ばす」など9種類の行動に変換して表示するパネルです。それぞれの行動に0.00〜1.00の強さがつき、一番強いものが大きな文字で表示されます（上の画像では、Foodをオンにした結果「Extending proboscis（口を伸ばす）」が最も強く出ています）。

右上に出ている「Activation」というラベルは、「まだ学習（トレーニング）していない段階なので、9つの行動それぞれについて独立に強さを計算しています」という意味です。9つの数字を全部足しても1にはなりません。仮に将来トレーニング済みのモデルに切り替わった場合は、ここが「Confidence（確信度）」というラベルに変わり、9つの行動から1つを選ぶ確率として表示されます。

NEURAL PIPELINE 中央下、横長の5マス

信号が脳の中を流れていく、大まかな5段階を表しています。

  • Sensory Input — 今まさに WORLD CONTROL から刺激を受け取っているセンサー細胞の数。
  • Sensory Neurons — その刺激を受けて、実際に反応している感覚系の神経細胞の数。
  • Interneurons — 脳の中で情報を中継・処理している神経細胞の数（一番数が多い段階です）。
  • Descending Neurons — 脳から、体（脚や翅など）に向けて指令を送り出す神経細胞の数。
  • Motor Output — 実際に体を動かす出力に対応する細胞の数。
Motor Output がいつも極端に小さい理由 このデータは首から上、つまり「脳の中」までしか記録されていません。脚や翅を実際に動かす先の配線までは対象になっていないため、Motor Outputに分類される細胞はもともとごく少数しかありません。これは不具合ではなく、公開されているデータそのものの範囲です。

NEURAL INSPECTOR 中央下、検索ボックスのあるパネル

気になる神経細胞を1つ選んで、じっくり観察できる場所です。中央の光る点をクリックするか、上の検索ボックスに番号・名前・部位名を入力して選びます。

選ぶと、次のことが分かります。

  • この細胞の種類・脳のどの部位にあるか・左右どちら側か・使っている神経伝達物質
  • 今この瞬間の発火レート（1秒間に何回信号を出しているか）と、直近10秒間の推移グラフ
  • この細胞が、他のどの細胞に信号を送っていて（Outgoing）、どの細胞から信号を受け取っているか（Incoming）。実際につながっている数・シナプス（つなぎ目）の数がそのまま表示されます
  • この細胞が、あらかじめ役割の分かっている神経回路（逃げる・止まる・歩く、など）のメンバーかどうか、そしてそこに直接つながっているかどうか

ここに表示される「INTERVENE」という枠が、次に説明する NEURAL HACKING の入り口です。

NEURAL HACKING 一番下のパネル

NEURAL INSPECTOR で選んだ1つの神経細胞に対して、直接手を加えて（介入して）、脳がどう変わるかを試せる場所です。

NEURAL INSPECTOR の中の「INTERVENE」に3つのボタンがあります。

  • Stimulate（刺激する） — この細胞に人工的な刺激を追加します。強さ（Hz）はスライダーで調整できます。
  • Suppress（抑える） — 逆方向の刺激を追加し、発火しにくくします。
  • Disable（黙らせる） — この細胞を完全に発火できない状態にします。どれだけ強い信号が来ても反応しなくなります。

どれか1つでも押すと、画面上部に赤いバナー「⚠ NEURAL INTERVENTION ACTIVE」が表示され、今どの細胞にどんな介入をしているかが一目で分かるようになります。「Reset all」でいつでも元通りにできます。

介入をセットした状態で「Run comparison」を押すと、「何もしなかった場合（Normal）」と「今の介入をした場合（Intervention）」を、同じ条件で並べて比較できます。トライアルの長さ（50 / 100 / 200ミリ秒）を選んで実行すると、次のことが数字で分かります。

  • Behavior — どちらの場合にどの行動が一番強く出たか
  • Neural activity / Spike count — 脳全体、および選んだ細胞自体が、どれだけ信号を出したか
  • Behaviour activations / Channel activity — 9つの行動それぞれの強さ、役割の分かっている神経回路それぞれの信号の量
  • Reaction time（反応時間） — 介入を始めてから、それぞれの神経回路が最初に信号を出すまでにかかった時間。ただし、介入前からすでに信号を出していた回路や、試した時間内に一度も反応しなかった回路については、無理に数字を出さず「latency not defined（測定できません）」「no spike in window（反応なし）」とそのまま表示されます。
この実験には、正直にお伝えすべき限界が4つあります
  • Suppress は理想化した抑制です。実際の抑制性の信号よりも強く効くことがあります。
  • Disable は配線図（コネクトーム）そのものを消しているわけではありません。その細胞をその場だけ黙らせているだけで、つながり自体は元のまま残っています。
  • 反応時間は、介入前から鳴っていた回路には定義できません。そういう場合は数字を出さず、理由を表示します。
  • 比較は1回きりの実験です。統計的に「確実に差がある」と主張しているわけではありません。

設定（歯車アイコン） 画面右上

画面右上の歯車アイコンから、見た目の描画品質を「High」と「Low」で切り替えられます。Lowにすると、水面に映る反射、光のにじみ（ブルーム）、影、輪郭のなめらかさなどの見た目の演出だけがオフになり、動作が軽くなります。シミュレーションの計算結果（発火・行動の判定など）はHigh/Lowでまったく同じです。お使いのパソコンが重いと感じたら、Lowに切り替えてみてください。

同じポップアップの「Reset camera」ボタンで、中央の3D映像のカメラ位置を初期状態に戻せます。

カメラモード 中央画面の左上

  • Free — マウスで自由に視点を動かせます。
  • Follow — カメラがハエを追いかけ続けます。
  • Orbit — カメラがハエの周りをゆっくり回り続けます。

4まず何をすればいいか

迷ったら、この順番で触ってみてください。

  1. まずは何もせず、少し眺めてみる右のNeural Activityの光る点が、何もしていなくてもわずかに揺れ動いているのが分かります。これは脳が完全にゼロの状態ではなく、常に小さな背景ノイズを持っているためです。
  2. 左のWORLD CONTROLで「Food」をONにしてみる中央のハエの様子や、右下のBEHAVIORパネルが「Extending proboscis（口を伸ばす）」に変わるのを確認してください。
  3. 中央の脳（Neural Activity）をクリックするか、下のNEURAL INSPECTORで気になる細胞タイプを検索してみる例えば「LPLC2」や「DNp01」と入力してみると、実在する細胞タイプが見つかります。選ぶとその細胞の役割や、今のつながり具合が分かります。
  4. 選んだ細胞を Disable（黙らせる）してみるNEURAL INSPECTOR内の「INTERVENE」から Disable を押すと、その細胞だけを黙らせた状態を体験できます。画面上部に警告バナーが出ます。
  5. そのまま一番下の NEURAL HACKING までスクロールし、「Run comparison」を押してみる「何もしなかった場合」と「その細胞を黙らせた場合」で、行動や信号の量がどう変わるかを数字で比較できます。
  6. 満足したら「Reset all」または「Reset World」で元に戻す「Reset all」は介入だけを解除します。「Reset World」はシミュレーション全体を最初からやり直します。

!正直にお伝えする注意点

上部の「Experiment」タブは、押しても何も起こりません 画面上部には「World / Neural / Experiment / Evolution」という4つのタブがありますが、これは見出しのようなもので、実際に画面を切り替える仕組みではありません。「World」「Neural」「Experiment」は押しても反応しませんが、それは壊れているのではなく、そもそも1枚の画面にすべての機能がすでに収まっているためです。「Experiment」というアイデアに相当する機能は、このガイドで説明したNEURAL HACKING パネル（Normal vs Intervention の比較実験）として、ページの下の方ですでに実際に動いています。
「Evolution」タブだけは、本当にまだ実装されていません こちらは灰色になっていて、実際にクリックできないようになっています。マウスを乗せると「Not implemented yet（まだ実装されていません）」という注記が出ます。今後の機能として予定されているだけで、現時点では使えません。
画面に出ている数字は、すべて本物のシミュレーション結果です 発火レート（Hz）、活動中の神経細胞数、スパイク（信号）の回数など、このページに表示される数字は、すべて今まさに計算されている実際のシミュレーション結果です。見栄えのためだけに用意された、架空の数字やあらかじめ決められた演出用の数字は一切ありません。何かの理由で数値が測定できない場合（たとえば反応時間が定義できない場合など）は、偽の数字を出す代わりに、理由をそのまま表示するようにしています。
Suppress / Disable は、元のデータそのものを書き換えているわけではありません NEURAL HACKING で神経細胞を刺激したり黙らせたりしても、本物のハエの脳の配線図（どの細胞がどの細胞とつながっているか）は一切変更されません。あくまで「今この瞬間だけ、もしこうしたらどうなるか」を試す、その場限りの実験です。ページを再読み込みしたり、「Reset all」「Reset World」を押せば、いつでも完全に元の状態に戻ります。
画面写真は旧タイトル表記の時点のものです このページ内のスクリーンショット（12枚）は、アプリの名前が「THE EMERGENCE」に変わる前、まだ「NEURAL GOD」と表示されていた時点で撮影したものです。ヘッダーのタイトル文字だけが写真と実際の画面とで異なりますが、機能や操作方法、画面の配置はすべて本文の説明どおりです。
